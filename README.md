**Flask URL Shortener**

A simple URL shortener built with Python (Flask).

Inspired by [this tutorial](https://www.youtube.com/watch?v=DBXq8ijk07s), 
but extended with additional features for better usability.


**Features**

Shorten long URLs into short codes 

View the shortened URL directly on the homepage after submission

Persistent storage using JSON 

Dashboard (/urls) showing all shortened links

Copy-to-clipboard button for quick sharing

Delete button to remove unwanted links

Navigation button from homepage to dashboard

**How to Run**

Install dependencies:

<pre>pip install Flask</pre>

Run the app:

<pre>python main.py</pre>

Open in your browser:

<pre>http://127.0.0.1:5000/</pre>
